Parametric Matrix Models#

参考: Parametric Matrix Models, arXiv:2401.11694v6

  • https://arxiv.org/html/2401.11694v6

補助資料: 公式コード（デモ）

  • https://codeocean.com/capsule/5052239/tree/v2

2. 導入: ニューラルネットとPMMの違い（直感）#

  • NN: 明示的な関数形（層の合成）

  • PMM: 行列方程式の解として出力が定義される（暗黙関数）

  • 物理由来の制約（対称性、保存量など）を構造で持たせやすい

  • 一般タスクにも使える（普遍近似性が理論的に示される）

3. PMMの基本形（概要）#

PMMは主行列と副行列から出力を作る。

  • 主行列: \(P_j( { {c_l} })\)（入力特徴 \( { {c_l} }\) に依存するHermitian/Unitary行列）

  • 固有ベクトル \(v_j^{(i)}\) を使って出力を構成

  • 副行列: \(S_k\) を用いた双線形形式

典型的なスカラー出力（イメージ）

\[ y = \left| \left(v^{(i)} \right)^\dagger S_k v^{(j)} \right|^2 \]

量子力学の期待値・遷移確率に似た形になる点が特徴。

4. AE-PMM と AO-PMM（2種類の基本形）#

4.1 AE-PMM（Affine Eigenvalue PMM）#

入力に対し主行列が**一次（アフィン）**に変化: $\( M(c)=nderline{M_0}+um_{l=1}^p c_lnderline{M_l} \)\( 出力は \)M(c)$ の固有値。

4.2 AO-PMM（Affine Observable PMM）#

固有ベクトルと副行列の双線形で複数出力を作る。 回帰・分類に便利（softmaxと組み合わせ可能）。

5. 一般タスク（回帰・分類）への適用#

5.1 回帰#

  • \( { {z_k} }\) を連続値として扱い、MSEで学習

  • 少ないパラメータで高精度になりやすい（論文報告）

5.2 分類#

  • \( { {z_k} }\) にsoftmaxを適用

  • 画像の場合はウィンドウごとのGram行列を使う設計が提案されている

6. なぜ情報系にも有効か（要点）#

  • 少パラメータで競争力のある性能

  • 解釈性: 行列要素や固有値の変化を追える

  • 外挿に強い可能性（解析接続・固有値構造）

  • NNの代替ではなく、構造的バイアスを入れる手法

8. まとめ#

  • PMMは行列方程式ベースの汎用モデル

  • 物理由来の発想だが、回帰・分類にも有効

  • 理論面: 普遍近似性（AE-PMMでも成立）

  • 実用面: 少ないパラメータで高性能・解釈性
